# Лабораторная работа 10 — Tasks

Ветка `10.1-tasks-room-datastore` содержит приложение для планирования задач
на выбранную дату и время.

## Возможности

- перелистывание дат вперёд от сегодняшней;
- выбор даты через календарь;
- создание задач с названием, описанием, датой и временем;
- просмотр, редактирование и удаление задач;
- сортировка по дате по возрастанию и убыванию, а также по алфавиту;
- сохранение последней выбранной даты и способа сортировки между запусками.

## Хранение данных

- задачи сохраняются локально через Room;
- выбранная дата и сортировка сохраняются через Preferences DataStore;
- экземпляр `DataStore<Preferences>` передаётся в репозиторий через DI-контейнер.

## Технологии

Kotlin, Jetpack Compose, Material 3, ViewModel, StateFlow, Coroutines, Room и
Preferences DataStore.
