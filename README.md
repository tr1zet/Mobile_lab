# Лабораторная работа 3 — Jetpack Compose

В репозитории каждое контрольное задание находится в отдельной локальной ветке:

- `3.1-compose-article` — экран статьи о Jetpack Compose;
- `3.2-task-manager` — экран завершённых задач;
- `3.3-compose-quadrant` — четыре информационных квадранта;
- `3.4-my-information` — персональная визитка.

## Как открыть задание

1. Переключитесь на нужную ветку.
2. Откройте корневую папку репозитория в Android Studio.
3. Дождитесь завершения Gradle Sync.
4. Запустите конфигурацию `app` на эмуляторе или устройстве с Android 7.0 (API 24) или новее.

Ветка `main` содержит только навигацию по лабораторной. Исходный код каждого приложения находится в соответствующей ветке.
