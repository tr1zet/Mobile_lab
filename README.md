# Сериалоскоп

Семестровая работа по мобильной разработке: каталог сериалов на Kotlin и Jetpack Compose с публичным API TVmaze.

## Запуск

Откройте проект в Android Studio, выберите Gradle JDK 21 (также подходит JDK 17), дождитесь синхронизации и запустите `app` на Android 7.0/API 24 или новее. Android SDK 35. Ключ API не требуется. Для первой загрузки нужен интернет.

Сборка в PowerShell (JAVA_HOME должен указывать на JDK 17 или 21):

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Для Windows с кириллицей в пути предусмотрен `verify.ps1`: запустите `.\verify.ps1` или `.\verify.ps1 -DeviceTests`. Скрипт временно создаёт короткий путь, запускает Gradle и удаляет этот путь после проверки; исходные файлы остаются в папке проекта.

APK: `app/build/outputs/apk/debug/app-debug.apk`.
Инструментальные проверки Room на подключённом устройстве/эмуляторе: `./gradlew :app:connectedDebugAndroidTest`.

## Возможности

- Каталог с постерами, рейтингами и постраничной загрузкой.
- Поиск с задержкой 500 мс и отменой предыдущего запроса. Запрос сохраняется через SavedStateHandle.
- Карточка сериала: описание без HTML-тегов, жанры, год, статус и список серий.
- Избранное с немедленным обновлением интерфейса и сохранением в Room.
- Кэш каталога, отдельных поисковых запросов, карточек и серий доступен после перезапуска без интернета.
- Состояния загрузки, ошибки с повтором, пустые результаты, заглушки отсутствующих изображений и оценок.
- Светлая и тёмная темы, адаптивная сетка, восстановление навигации и позиции прокрутки.

Интерфейс русский. Названия и описания отображаются на языке источника; автоматического перевода нет. Офлайн-поиск показывает сохранённые результаты именно этого запроса. Новые запросы требуют сети. Изображения кэширует Coil на диске по мере просмотра; наличие всех постеров офлайн не гарантируется. Сервис предоставляет метаданные сериалов, просмотр видео в приложение не входит.

## Архитектура и критерии задания

Исходный пакет `com.example.tasks` оставлен для совместимости структуры проекта; приложение имеет отдельный applicationId `com.example.serialoscope` и базу `series.db`.

| Критерий | Реализация |
| --- | --- |
| MVVM, слои, Repository | `series/model`, `series/data/local`, `series/data/remote`, `series/ui`; ручная передача зависимостей из `SeriesApplication` |
| ViewModel и State/Event | `CatalogUiState`, `FavoritesUiState`, `ShowUiState`; StateFlow; обработчики событий во ViewModel |
| Retrofit и обработка результатов | `TvmazeApi`, `RefreshResult`, обработка IOException и HTTP 404/429/5xx |
| Coroutines и lifecycle | suspend-запросы Retrofit и Room, viewModelScope, collectAsStateWithLifecycle; CancellationException пробрасывается |
| Compose и сохранение состояния | SavedStateHandle для поиска, rememberSaveable для раскрытого описания, ViewModel при повороте |
| Navigation Compose | три маршрута; ID сериала передаётся как NavType.IntType |
| Room и офлайн | каталог и результаты поиска связаны с сериалами через collection_entries; серии и избранное в отдельных таблицах |
| Синхронизация | UI читает только Room; сначала показывает кэш, затем обновляет сетью; успешные ответы записываются транзакционно; при ошибке кэш сохраняется |
| UI/UX | переиспользуемые карточки и сообщения, прокрутка, повтор запроса, пустые списки, индикаторы загрузки |

Обновление каталога начинает список с первой страницы. «Загрузить ещё» добавляет следующую страницу. Избранное не перезаписывается сетевыми ответами. Нумерация каталога TVmaze основана на ID, поэтому это общий каталог, а не рейтинг популярности.

## Проверка перед защитой

1. Запустить с интернетом, дождаться каталога, загрузить следующую страницу.
2. Найти `Sherlock`, открыть карточку, дождаться списка серий, добавить в избранное.
3. Повернуть устройство: запрос, карточка и избранное сохраняются.
4. Закрыть приложение, отключить сеть, снова запустить: ранее загруженные данные остаются.
5. Открыть избранное и сохранённую карточку: описание и серии доступны.
6. Ввести новый запрос без сети: понятная ошибка и кнопка повтора.
7. Включить сеть и нажать «Повторить»: данные обновляются.

Автоматические unit-тесты проверяют debounce, восстановление запроса, реактивность избранного, показ кэша при ошибке, null-поля API и отмену работы ViewModel. Инструментальные тесты проверяют настоящий Room: закрытие и повторное открытие базы, сохранение избранного при обновлении, кэш серий, разделение поисков и добавление страниц.

Проверено 27 ноября 2026: debug APK собран, 8 unit-тестов прошли, lint — 0 ошибок (6 предупреждений о target SDK и прежних ресурсах). На эмуляторе Android 37.1 напрямую через AndroidJUnitRunner прошли 2 теста Room. Вручную проверены загрузка каталога и постеров, карточка с 39 сериями, избранное и перезапуск без сети.
