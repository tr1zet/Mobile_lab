# Лабораторная работа 8 — My City Кемерово

- `8.2-my-city-kemerovo` — рекомендации по интересным местам Кемерово;
- пять категорий и по три места в каждой;
- фотографии хранятся локально и работают без интернета;
- Jetpack Navigation Compose для переходов между экранами;
- ViewModel, StateFlow и однонаправленный поток данных;
- адаптивные макеты для телефона, планшета и широкого экрана.

## Запуск

Откройте проект в Android Studio, выполните Gradle Sync и запустите конфигурацию `app` на эмуляторе Android.
